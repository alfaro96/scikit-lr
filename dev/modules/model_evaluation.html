2. Metrics and scoring: evaluating the rankers#

sklr.metrics implements functions that compare the true rankings of some samples with the rankings that an estimator predicts for them, and the scorers that bring these functions to the model selection tools of scikit-learn. Each function computes a correlation or a distance between the true and the predicted ranking of each sample, and returns their average, which may be weighted with sample_weight.

The rankings follow the representation described in Ranking representation, and they must be complete: the metrics reject rankings with unranked labels, in the true rankings as well as in the predicted ones.

2.1. Scoring#

The model selection tools of scikit-learn, such as sklearn.model_selection.cross_val_score() and sklearn.model_selection.GridSearchCV, evaluate an estimator with its score method unless they are given a scorer with the scoring parameter. The score method of the label rankers computes Kendall’s \(\tau\), and that of the partial label rankers computes the \(\tau_x\) coefficient, both described below.

scikit-learn only accepts the names of its own scorers as values of scoring, so the scorers of scikit-lr are passed as objects, which get_scorer() gets from their names:

Name

Function

"kendall_tau"

kendall_tau_score()

"tau_x"

tau_x_score()

"neg_kendall_distance"

kendall_distance()

As in scikit-learn, greater values of a scorer are better, so the scorer of a distance returns it negated. get_scorer_names() lists the names:

>>> from sklr.metrics import get_scorer, get_scorer_names
>>> get_scorer_names()
['kendall_tau', 'neg_kendall_distance', 'tau_x']
>>> get_scorer("neg_kendall_distance")
make_scorer(kendall_distance, greater_is_better=False, response_method='predict')

The scorer is then passed as scoring, for instance with cross_val_score(ranker, X, y, scoring=get_scorer("kendall_tau")). A scorer can also be made from a metric with sklearn.metrics.make_scorer(), which is how the scorers above are built. When metadata routing is enabled, the scorers receive sample_weight if it is requested with their set_score_request method.

2.2. Label ranking metrics#

The metrics of label ranking compare rankings without ties, and they reject the rankings with tied labels.

2.2.1. Kendall’s \(\tau\)#

kendall_tau_score() computes Kendall’s \(\tau\) [kendall_new_1938], which scores each pair of labels with +1 if the true and the predicted ranking order it in the same way (a concordant pair) and with -1 otherwise (a discordant pair). Given the positions \(y\) and \(\hat{y}\) of the \(m\) labels in the true and the predicted ranking, let \(a_{ij}\) be 1 if \(y_i < y_j\) and -1 if \(y_i > y_j\), and likewise \(\hat{a}_{ij}\) for \(\hat{y}\). Then

\[\tau(y, \hat{y}) = \frac{2}{m(m - 1)} \sum_{i < j} a_{ij} \hat{a}_{ij},\]

which ranges from -1, when one ranking is the reverse of the other, to 1, when both rankings are equal:

>>> from sklr.metrics import kendall_tau_score
>>> y_true = [[1, 2, 3], [3, 2, 1]]
>>> y_pred = [[1, 2, 3], [1, 3, 2]]
>>> kendall_tau_score(y_true, y_pred)
0.333...

Without ties, all the variants of Kendall’s \(\tau\), such as \(\tau_a\) and \(\tau_b\), are the same. They differ in how they handle ties, which is why the metrics of partial label ranking use the \(\tau_x\) coefficient instead, described in Partial label ranking metrics.

2.2.2. Kendall distance#

kendall_distance() counts the discordant pairs of labels, which is also the minimum number of swaps of adjacent labels that turn one ranking into the other. By default, it is divided by the number of pairs, \(m(m - 1) / 2\), so that it ranges from 0 to 1 and is related to Kendall’s \(\tau\) by \(d = (1 - \tau) / 2\):

>>> from sklr.metrics import kendall_distance
>>> kendall_distance(y_true, y_pred)
0.333...
>>> kendall_distance(y_true, y_pred, normalize=False)
1.0

2.3. Partial label ranking metrics#

The metrics of partial label ranking compare rankings that may have ties.

2.3.1. \(\tau_x\)#

tau_x_score() computes the \(\tau_x\) rank correlation coefficient [emond_new_2002], which extends Kendall’s \(\tau\) to rankings with ties. Let \(a'_{ij}\) be 1 if \(y_i \leq y_j\), that is, if label \(i\) is ahead of or tied with label \(j\), and -1 if \(y_i > y_j\), for \(i \neq j\). Then

\[\tau_x(y, \hat{y}) = \frac{1}{m(m - 1)} \sum_{i \neq j} a'_{ij} \hat{a}'_{ij}.\]

Unlike Kendall’s \(\tau_b\), its denominator does not depend on the ties, so a ranking with all its labels tied has a coefficient of 1 with itself and of 0 with any ranking without ties. For rankings without ties, it is equal to Kendall’s \(\tau\):

>>> from sklr.metrics import tau_x_score
>>> tau_x_score([[1, 1, 1]], [[1, 1, 1]])
1.0
>>> tau_x_score([[1, 1, 1]], [[1, 2, 3]])
0.0
>>> tau_x_score(y_true, y_pred)
0.333...

The \(\tau_x\) coefficient is also equivalent to the Kemeny-Snell distance \(d\) between rankings with ties, by \(\tau_x = 1 - 2 d / (m(m - 1))\).

References

[kendall_new_1938]

M. G. Kendall, “A new measure of rank correlation”, Biometrika, vol. 30, no. 1/2, pp. 81-93, 1938.

[emond_new_2002]

E. J. Emond and D. W. Mason, “A new rank correlation coefficient with application to the consensus ranking problem”, Journal of Multi-Criteria Decision Analysis, vol. 11, pp. 17-28, 2002.
