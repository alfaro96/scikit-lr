LabelwiseLabelRanker#

class sklr.reduction.LabelwiseLabelRanker(estimator: object | None = None, *, loss: Literal['absolute_error', 'squared_error'] = 'absolute_error', n_jobs: int | None = None)#

Label ranker that learns the position of each label separately.

The labelwise decomposition of [cheng_labelwise_2013] fits, for each label, a probabilistic classifier that predicts the probability of each of its positions, and predicts the ranking that minimizes the expected loss under those probabilities, as if the positions of the labels were independent. The training rankings may be incomplete, as if their unranked labels had been removed at random from complete rankings, with the default estimator or any other that implements fit_likelihood.

Read more in the User Guide.

Parameters:
estimatorestimator object, default=None

Probabilistic classifier fitted to the positions of each label, from 1 to the number of labels, which implements fit and predict_proba. The positions are ordered, so an ordinal classifier suits them best. None means the ordinal logistic regression of [cheng_labelwise_2013].

To learn from incomplete rankings, the estimator also has to implement fit_likelihood(X, likelihood, classes, sample_weight=None), as the default one does, which is then used instead of fit for all the training rankings. likelihood[i, k] is the probability of what is observed of sample i if its class is classes[k], and the method maximizes the sum over the samples of the logarithm of likelihood[i] @ proba[i], weighted by sample_weight, where proba[i] holds the probabilities of the classes of sample i that predict_proba predicts afterwards. It returns the fitted estimator, with classes_ set to classes, which are the positions of the label. An estimator without fit_likelihood only accepts complete rankings, and predicts a zero probability for the positions that a label never takes in them. If sample_weight is given, the method that fits the estimator has to support it.

loss{“absolute_error”, “squared_error”}, default=”absolute_error”

Loss between the true and the predicted position of each label, summed over the labels, whose expected value the predicted ranking minimizes. "absolute_error" is the absolute difference, whose sum is an affine transformation of Spearman’s footrule, and the ranking solves an assignment problem. "squared_error" is the squared difference, whose sum is an affine transformation of Spearman’s \(\rho\), and the ranking sorts the labels by increasing expected position. In both cases, among the rankings of minimum expected loss, the predicted one gives the smallest position to the first label, then to the second one, and so on.

n_jobsint, default=None

Number of jobs to run in parallel to fit the estimators of the labels. None means 1 unless in a joblib.parallel_backend context. -1 means using all processors. See Glossary for more details.

Attributes:
estimators_list of estimator objects or None

Estimator fitted to the positions of each label, or None for a label that no training ranking of positive weight ranks together with another label, whose positions are predicted as equally likely.

n_features_in_int

Number of features seen during fit.

feature_names_in_ndarray of shape (n_features_in_,)

Names of features seen during fit. Defined only when X has feature names that are all strings.

Notes

The estimator of each label \(y_j\) predicts the probability \(P_j(r \mid \boldsymbol{x})\) that its position is \(r\), for \(r = 1, \dots, n\), given an instance \(\boldsymbol{x}\). The expected loss of putting \(y_j\) at position \(r\) is

\[L_j(r) = \sum_{r'=1}^n \ell(r', r) P_j(r' \mid \boldsymbol{x}),\]

with \(\ell(r', r) = |r' - r|\) for loss="absolute_error" and \(\ell(r', r) = (r' - r)^2\) for loss="squared_error", and the predicted ranking is

\[\hat\pi = \arg\min_{\pi \in \Omega} \sum_{j=1}^n L_j(\pi(j)),\]

where \(\Omega\) is the set of the rankings of the \(n\) labels. It is an assignment of the labels to the positions [cheng_labelwise_2013]. With the absolute difference, it is solved by scipy.optimize.linear_sum_assignment(). With the squared difference, \(\sum_{j=1}^n \pi(j)^2\) is the same for all the permutations, so \(\hat\pi\) sorts the labels by increasing expected position \(\sum_{r=1}^n r P_j(r \mid \boldsymbol{x})\).

The default estimator is the cumulative logit model of equation (20) of [cheng_labelwise_2013], whose coefficients have the \(L_2\) penalty of LogisticRegression with its default strength, and whose thresholds are not penalized. Its likelihood is maximized by L-BFGS-B, and fit() issues a ConvergenceWarning if it does not converge within 100 iterations.

An incomplete ranking \(\sigma\) only ranks a subset \(\mathcal{Y}(\sigma) \subseteq \mathcal{Y}\) of the labels, with \(m = |\mathcal{Y}(\sigma)| \leq n\) labels, and if the other \(n - m\) labels were removed at random from a complete ranking, the probability of observing a ranked label \(y_j\) at position \(\sigma(j)\) is

\[\sum_{r=\sigma(j)}^{\sigma(j) + n - m} P_j(r \mid \boldsymbol{x}) \frac{\binom{r - 1}{r - \sigma(j)} \binom{n - r}{n - m - r + \sigma(j)}}{\binom{n}{m}},\]

equation (16) of [cheng_labelwise_2013]. The fractions of binomial coefficients are the likelihood that fit_likelihood receives, so that the model of each label maximizes the weighted log-likelihood of the rankings that rank that label, equation (17) of [cheng_labelwise_2013], which is the usual one for complete rankings. The rankings that do not rank the label, or rank it alone, observe it with the same probability for any model, so they are left out, as are those of zero weight. If no ranking is left for a label, fit() warns with a UserWarning, and the positions of the label are predicted as equally likely.

References

[cheng_labelwise_2013] (1,2,3,4,5,6)

W. Cheng, S. Henzgen and E. Hüllermeier, “Labelwise versus pairwise decomposition in label ranking”, in Proceedings of the Workshop on Lernen, Wissen & Adaptivität, pp. 129-136, 2013.

Examples

>>> from sklr.reduction import LabelwiseLabelRanker
>>> X = [[0], [1], [2], [3]]
>>> y = [[1, 2, 3], [2, 1, 3], [1, 2, 3], [3, 1, 2]]
>>> ranker = LabelwiseLabelRanker().fit(X, y)
>>> ranker.predict([[1.1], [2.2]])
array([[1, 2, 3],
       [2, 1, 3]])

The training rankings may be incomplete, with np.nan for the unranked labels:

>>> import numpy as np
>>> y = [[1, 2, np.nan], [2, 1, 3], [1, np.nan, 2], [3, 1, 2]]
>>> ranker = LabelwiseLabelRanker().fit(X, y)
>>> ranker.predict([[1.1], [2.2]])
array([[2, 1, 3],
       [2, 1, 3]])
