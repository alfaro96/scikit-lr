# Security Policy

## Supported Versions

Only the latest minor release of scikit-lr receives fixes, security fixes included.

| Version | Supported          |
| ------- | ------------------ |
| 0.3.x   | :white_check_mark: |

## Reporting a Vulnerability

Please report security vulnerabilities privately by opening a new [GitHub security advisory](https://github.com/alfaro96/scikit-lr/security/advisories/new), not in a public issue.

If the vulnerability is accepted, a fix is prepared privately and published in a patch release of the latest minor release as soon as possible, depending on the complexity of the fix.
