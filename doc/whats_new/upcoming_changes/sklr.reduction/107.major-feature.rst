* :class:`reduction.LabelwiseLabelRanker` fits a probabilistic classifier to the
  positions of each label, by default an ordinal logistic regression, and predicts
  the ranking that minimizes the expected absolute or squared error of the
  positions. It learns from incomplete rankings with the default classifier or any
  other with a ``fit_likelihood`` method.
  By :user:`Juan Carlos Alfaro Jiménez <alfaro96>`.
