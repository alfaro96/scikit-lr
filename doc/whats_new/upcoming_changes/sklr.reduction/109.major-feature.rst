* :class:`reduction.PairwiseLabelRanker` fits a probabilistic classifier to each
  pair of labels, by default a logistic regression, and ranks the labels by the sum
  of the probabilities that each one is ahead of the others, which minimizes the
  expected squared error of the positions when the probabilities are right. It
  learns from incomplete rankings, fitting the classifier of each pair to the
  rankings that rank both of its labels.
  By :user:`Juan Carlos Alfaro Jiménez <alfaro96>`.
