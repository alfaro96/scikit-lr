# Changelog fragments

This directory contains the changelog entries of the pull requests merged since the last release, one file per change, which `towncrier` joins into the release history of the upcoming version when it is released, with the template `towncrier_template.rst.jinja2`.

See [how to write a changelog entry](https://alfaro96.github.io/scikit-lr/dev/developers/contributing.html#changelog) in the contributing guide.
